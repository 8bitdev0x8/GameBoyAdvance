# Original experimental board support

Explicit guarded IWRAM/VRAM arenas, registered allocator glue and immutable native-function lookup cache. These are support components, not a complete emulator. They require the separately obtained runtime API and board integration; no game translations, ROM/BIOS, generated native image or upstream core is included. See ../../GBAPrototype/PERFORMANCE-2026-10-26.md for measured scope and limitations.
